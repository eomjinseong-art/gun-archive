# 건 아카이브

영화·드라마에 자주 나온 권총을 정리한 비공식 영화·문화 아카이브. Next.js App Router, 정적 생성.

- 데이터: `data/guns.ts`, `data/films.ts`, `data/scenes.ts`, `data/gun-images.json`
- 영화 속 등장 기록은 IMFDb에서 확인한 것만 적습니다. 총기의 구입·제작·개조·사용 정보는 다루지 않습니다.
- 사진: 위키미디어 커먼스 자유 라이선스 사진(같은 모델·계열 참고 사진), `/credits`에 작가·라이선스 표기
- 방문자 수: Abacus `gun-archive` / `visits` (하루 1회, 테스트 방문 제외)
- 광고: 쿠팡 파트너스 (푸터 배너 + 하단 고정 배너 + 본문 카드, 페이지당 최대 3개)
